# MCP demo data folder

Place practice files here and point the demo MCP server at this folder.
Only files inside this folder can be read by the AI through the demo server.

## hello.txt

Hello from the MCP demo folder!

This file exists so you can try the demo server right away:

    node demo-server/server.js

Then ask your connected AI assistant to read hello.txt. Nothing was copied
and pasted by hand — the AI asked the MCP server, and the server read the file.

This folder is read-only for the demo server. It cannot reach the rest of
your computer.
